# Dataset attribution

Dataset: PlantVillage, 54,305 color leaf images in 38 categories. Public archive mirror: [NalinKarthik/PlantVillage](https://huggingface.co/datasets/NalinKarthik/PlantVillage), file `data.zip` (downloaded 2026-10-25). The mirror lists the dataset under **CC BY-SA 3.0** and notes that it duplicates [mohanty/PlantVillage](https://huggingface.co/datasets/mohanty/PlantVillage). The archive SHA-256 was checked against the listing: `fba30c6a7965e49be94b47a62f8aff6cfb1c35c27f475f22092b56db41745e84`.

Original dataset publication: Mohanty, S. P., Hughes, D. P., & Salathé, M. (2016). Using deep learning for image-based plant disease detection. *Frontiers in Plant Science*, 7, 1419. https://doi.org/10.3389/fpls.2016.01419

Please review the source terms before redistributing the dataset or a model derived from it. Dataset files are not included in the source ZIP; follow the `README.md` workflow to download them separately.
